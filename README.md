# CircuTown

**Sime Darby Property University Hackathon 2026 — Planet Track**  
Team RAHHHHH · Universiti Malaya

CircuTown is our concept for making recycling more rewarding and visible within a township. Residents use the app to connect to a proposed smart recycling bin, earn CircuPoints for accepted materials and redeem points at participating local shops. Precinct Wars adds a community leaderboard to encourage continued participation.

## Demo

- [Try the interactive app](https://junyuong.github.io/CircuTown-SD-Hackathon/)
- [Watch the guided walkthrough](https://junyuong.github.io/CircuTown-SD-Hackathon/?demo=1)

The prototype includes:

- **Circular Bin:** QR pairing and a simulated item verification and weighing process.
- **CircuPoints:** A resident wallet and example rewards from local merchants.
- **Precinct Wars:** Neighbourhood recycling leaderboards and community events.
- **CircuShuttle:** An exploratory on-demand electric shuttle booking interface.

## Run locally

Download or clone the repository and open `index.html` in a browser. No build step is needed.

## Current scope

This is an interactive software prototype for the hackathon. The kiosk hardware, material sensing, recycling totals, voucher redemption, shuttle tracking and journey estimates are simulated. The 50× points setting is only used to demonstrate leaderboard changes during the walkthrough.
