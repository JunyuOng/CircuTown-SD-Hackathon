# CircuTown

**A Gamified Circular Economy and Sustainable Township Engagement Platform**  
**Team RAHHHHH** | Sime Darby Property University Hackathon 2026

CircuTown explores how verified recycling, community participation, local merchant rewards, and future shared mobility can become one connected township experience.

## Live demo

- **Interactive prototype:** https://junyuong.github.io/CircuTown-SD-Hackathon/
- **Guided product walkthrough:** https://junyuong.github.io/CircuTown-SD-Hackathon/?demo=1

> GitHub Pages must be enabled in repository Settings → Pages for the above links to work.

## Experience

- **Circular Bin:** Simulated smart recycling kiosk, QR pairing, identification and weighing of recycled items, and Circular Points rewards.
- **CircuPoints and local rewards:** A wallet and illustrative merchant voucher redemption.
- **Precinct Wars:** Gamified township participation, ranks, and community activities.
- **CircuShuttle:** Concept demo for an on-demand township electric shuttle with illustrative booking and tracking.
- **Guided presentation:** Automated walkthrough with UI interactions and captions.

## Run locally

Open `index.html` in a current desktop browser. To start the walkthrough automatically, append `?demo=1` to a deployed site URL.

## Prototype disclosure

This is an interactive hackathon concept prototype, **not** a production service. Kiosk sensing, balances, leaderboard changes, voucher flows, shuttle location and ETA are simulated/demo data. The 50× boost is specifically a presentation device, not an actual points policy. No live smart bin, merchant redemption integration, or transport dispatch is claimed.
